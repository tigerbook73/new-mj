# Junk 普通型路线门禁

## 目标

让普通标准型结构策略只在普通型明确占优的决策节点参与 A/B；七对倾向、清/混一色、
碰碰胡倾向以及普通型/七对结构打平的节点只计数，候选在这些节点回退到 weighted。
因此配对对局的终局分差只来自普通型节点的策略变化，不再把已明确延后的路线混入门禁。

## 固定分类

- `ordinary-standard`：普通型结构严格优于七对（或已有副露使七对不可用），且没有下列
  特殊路线信号；候选使用 structural。
- `seven-pairs`：七对按向听、存活进张种类、存活进张张数的固定结构序严格优于普通型。
- `other-special`：全部已知手牌/副露只包含一种数牌花色（可带字牌），或无 chi 且
  `非 chi 副露数 + 手牌对子/刻子种数 >= 4`。
- `ambiguous`：普通型与七对的三项结构事实完全打平。

后三类候选均调用当前 weighted 策略，只写分类计数，不作为普通型结构策略的直接决策样本。
分类不使用 `JunkWeights`，也不声称覆盖未来新增的番型路线。

## 验收

- 单测固定七对、单花色和普通多花色分类。
- `structural compare` 报告四类决策数；被排除节点必须走 weighted fallback。
- 15 seeds / 30 场换位配对无失败，候选 P95 不高于 50ms，且候选总分不低于 weighted
  才能通过当前生产质量门禁。
