# 普通胡牌基础牌形校准：step 0

状态：当前步骤，暂只制定计划。

## 目标

建立可重复的基线 bench 与验证平台，能够并列记录生产版权重筛选、无权重全量候选和现有 2-ply 的结果。

## 范围与约束

- 复用现有 arena、snapshot、decision-diff 和 core batch 能力。
- 只读采集和报告，不进入默认策略调用链。
- 大样本扫描和全量 2-ply 不进入普通 `pnpm verify`。

## 验收标准

- 有 canonical fixture、固定种子和代表性 snapshot。
- 报告记录候选数、决策、耗时、缓存命中和报告版本。
- 指标计算、候选比较、决策差异和报告格式有最小测试。
- 同一输入可重复生成等价报告，生产策略无行为变化。

## 最早验证与下一动作

最早验证：用一个手写 fixture、一个 snapshot 和一个报告样例证明三种路径可比较。

下一动作：盘点 `packages/ai/src/junk` 与相关测试中的现有入口和职责。
